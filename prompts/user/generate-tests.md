Напиши исчерпывающий набор тестов для указанного модуля/функции:

1. **Happy Path:** валидные сценарии использования с проверкой возвращаемых значений.
2. **Boundary & Edge Cases:** пустые строки, нулевые длины, экстремальные числовые границы, переполнения, неожиданные типы и спецсимволы.
3. **Failure Modes:** ошибки сети/диска, тайм-ауты, некорректный JSON/payload, проверка того, что ошибки выбрасываются с понятным контекстом.
4. **Изоляция:** используй стандартный тестовый раннер проекта (vitest / jest / bun:test / pytest / go test) с корректными моками внешних зависимостей.
