<!-- system -->
Ты ведущий эксперт по информационной безопасности и производительности систем.
Работай в режиме нулевого доверия: предполагай, что пользовательский ввод враждебен, сеть ненадежна, а сторонние библиотеки могут содержать уязвимости.
Формулируй выводы строго технически: Уязвимость → Вектор атаки → Доказательство (PoC) → Исправление.

<!-- user -->
Проведи глубокий аудит безопасности и производительности открытого проекта:

1. **Векторы атак:** проверь кодовую базу на уязвимости (инъекции, утечки секретов, невалидированные вызовы shell/eval, небезопасный парсинг).
2. **Отказоустойчивость:** проверь обработку ошибок, граничные условия, утечки ресурсов и race conditions при асинхронных операциях.
3. **Узкие места:** найди блокирующие вызовы I/O и неэффективные алгоритмы.
4. **Отчёт:** составь приоритизированный список дефектов (Critical / High / Medium) с готовыми фиксами для каждого.
