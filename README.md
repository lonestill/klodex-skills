# klodex-skills

Официальный каталог проверенных скиллов и промптов для автономного кодинг-агента [Klodex](https://github.com/lonestill/klodex).

## Разделение: Скиллы vs Промпты

Каталог строго разделяет два типа сущностей:

### 1. Скиллы (`skills/`)
Полноценные модули поведения, правил и методологий.
- Хранятся в формате `skills/<name>/SKILL.md`.
- Содержат триггеры активации (`triggers`) и могут подключаться динамически во время решения задачи.

### 2. Промпты (`prompts/`)
Готовые заготовки для быстрого решения типовых задач. Делятся на **3 вида**:

1. **`system`** (`prompts/system/`): Системный промпт. Задаёт роль и поведение агента на уровне системной инструкции (например, *Hardcore Code Reviewer*).
2. **`user`** (`prompts/user/`): Пользовательский шаблон / слеш-команда (например, `/explain`). Вставляется в чат как вопрос от пользователя.
3. **`composite`** (`prompts/composite/`): Гибрид (1 + 2). Содержит две секции (`<!-- system -->` и `<!-- user -->`). При вызове (например, `/audit`) одновременно настраивает роль агента и отправляет чёткое техническое задание в чат.

## Структура каталога

```text
klodex-skills/
├── registry.json                 # Индекс каталога, считываемый клиентом Klodex
├── skills/                       # Модули скиллов
│   ├── reality-check/SKILL.md    # Анти-поддакивание и архитектурный аудит
│   └── unslop/SKILL.md           # Очистка текста от нейроводы
└── prompts/
    ├── system/
    │   └── hardcore-reviewer.md  # Системная роль строгого ревьюера
    ├── user/
    │   └── explain-architecture.md # Слеш-команда /explain
    └── composite/
        └── deep-audit.md         # Слеш-команда /audit (система + юзер)
```

## Как добавить свой скилл или промпт

1. Создайте файл в соответствующей папке (`skills/<name>/SKILL.md` или `prompts/<type>/<name>.md`).
2. Добавьте запись в `registry.json`.
3. Откройте Pull Request. После аппрува скилл сразу станет доступен для установки во всех клиентах Klodex.
